# 분석 수용 검사: 합성 A~F

기준 기간은 KST 2026-01-01 이상 2026-02-01 미만, 조회 완료 기준은 2026-02-01 00:00 KST다. 완전 수집 fixture 범위는 2025-12-01 이상 2026-02-01 미만이다. 실제 회원·학생 데이터는 사용하지 않았다.

`engagement.mjs`는 서버 내부 회원 ID로만 연결한다. 결과에는 개인 ID·이름·A/B별 행·고정 가명·해시 목록이 없다. 아래 표는 합성 계산값이며 운영 공개 승인이 아니다. 이 분석 함수는 MCP 도구로 노출하지 않았다.

### 신청 개수 분포와 동일인

현재 유효 JOIN/WAITLIST의 서로 다른 프로그램 수를 회원 ID의 Set으로 내부 계산한다. 사전신청과 현장참여를 구분할 수 있는 fixture에서는 사전신청자 4명 모두 1개 프로그램, 실제 참석자는 1개 프로그램 2명·2개 프로그램 1명이다. 같은 프로그램 두 회차 출석을 2개 프로그램 신청으로 바꾸지 않는다. 취소자 F와 확정 결석 C를 실제 출석에 포함하지 않는다. 기본 집계 엔진에는 `unique_applicants`도 추가했으며 이는 JOIN/WAITLIST/CANCELLED의 현재 응답 인원 합집합이고, 상태 변경 이벤트 누적 신청자나 사전 신청자만의 수는 아니다.

### 관찰 기간·분모

30일 추적은 기준 다음날부터 30번째 날까지이며 다음날 00:00에 관찰이 완료된다. 1/1 기준이면 1/2~1/31을 모두 수집해야 하므로 2/1부터 분모에 들어간다. 1/31 D는 관찰 중으로 따로 표시한다. 센터 재방문 기준은 **분석 기간 첫 관측 방문**이다. A·B의 과거 방문이 있으므로 이 fixture 결과를 생애 최초 방문자의 재방문율이라고 부르지 않는다. 최초 방문 분석은 이전 전체 이력 완전성이 별도로 필요하다.

전후 비교는 같은 참석자의 기간 내 첫 확정 참석일을 기준으로 전 28일·후 28일, 기준일 제외다. 방문일수와 방문 세션 수를 구분한다. 관찰 미완료와 이전 수집 부족을 별도로 표시하며 분모를 섞지 않는다. 실측 체류는 퇴실 누락·0분·추정 시간을 분리한다. 프로그램이 방문 증가를 일으켰다는 인과효과나 활동 감소의 이탈 원인을 주장하지 않는다.

전환 흐름은 다른 날짜의 확정 출석 순서에서 연속 같은 프로그램을 건너뛰고, 한 사람이 같은 프로그램 쌍을 여러 번 이동해도 쌍별 인원은 한 번만 센다. 같은 날 여러 프로그램은 시간 순서를 확정할 수 없어 그 사람의 순서 흐름을 보류한다. 별도의 프로그램 이후 30일 이동 비율은 고정 추적 기간이 끝난 사람만 분모에 둔다.

### 현재 소스에서 가능한 것과 미확인 사항

현재 9개 테이블 읽기 필드로 현재 응답 기준 고유 신청자/프로그램 개수, 방문 세션·방문일·실측 체류는 계산할 수 있다. 기본 `attendanceBasis=recorded`는 현재 JOIN+is_attended 기록 및 개방형 출석을 기준으로 참여 개수 분포와 기록상 프로그램 흐름을 `limited`로 제공한다. 이를 실제 출석 확정이나 전체 이력으로 포장하지 않는다. 별도 확정 근거를 요구하는 `attendanceBasis=confirmed` 모드도 합성 검사했다. 원천 조회 완전성과 중복 충돌은 반드시 검증해야 한다.

합성 fixture의 `application_origin`, `attendance_confirmed`, 수집 coverage 및 `stateAtOccurrence`는 **현재 운영 DB에서 확인된 필드가 아니다**. 실제 읽기 어댑터는 이 증명을 제공하지 않으며 테스트 값을 운영에 복사하지 않는다. 따라서 현재 데이터로 정확한 사전신청자 출석률, 현장 참여 제외, 역사적 확정 상태, 확인된 출석 기반 전환·재참여와 추적 완전성을 증명했다고 할 수 없다.

로컬 `supabase/manual/proposals/20260929_*application*history.sql`에는 취소 시도 기록 제안이 있지만 모든 상태 변경/출석 확정/사전신청 출처/수집 누락을 증명하는 전체 이력은 아니다. staff walk-in 로직도 기존 응답을 JOIN+is_attended로 쓰므로 현장 참여를 현재 응답만으로 완전히 분리한다고 가정하지 않는다. 운영 적용 상태는 이번에 조회하지 않았다.

사전신청 출처·확정 출석·상태 기준시점·완전 수집 기간이 없으면 엄밀한 해당 분석은 unavailable/limited/incomplete로 표시한다. 기록 기반 참여 분포·현재 신청 수까지 모두 불가로 만들지는 않는다. 단순 is_attended=true를 새로운 확정 출석 증거로 바꾸거나 누락된 이력을 추정하지 않는다. 프로그램 일정이 없으면 created_at을 출석일로 대신하지 않는다. 완전 이력이 없는 생애 최초 방문·이탈 원인·인과효과는 현재 범위에서 답할 수 없다.

정적 코드/스키마 확인으로 구분한 항목은 다음과 같다. 운영 레코드나 원격 schema는 조회하지 않았다.

### 공개 정책

정확 n과 분모 계산 검증은 외부 공개 허용과 별개다. 분포의 1명 셀, 전체에서 다른 셀을 뺀 보완집단, 프로그램 쌍과 작은 참석자 집단, 전후 평균과 분모, 겹치는 기간과 재조회는 개인 추정을 가능하게 할 수 있다. 결과에는 `publication.status=review_required`를 붙이고, 기존 공개 정책을 자동 확대하지 않았다. 실제 분석 도구 추가는 지표·코호트·추적 기간·셀·연속 질의 정책을 검토한 뒤 진행한다.

검사 파일은 `scripts/test-engagement-analysis.mjs`와 `scripts/fixtures/engagement-fixture.mjs`다. 중복 원천행·입력 순서·직원 제외 기본 경계·KST 자정·취소·대기·미확정·동시 프로그램·음수 순서 및 중첩 입실 품질·추적 미완료를 검사한다. 정밀 시각을 외부 출력하지 않는다.
