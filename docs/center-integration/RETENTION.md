## 계산과 수집

- 기존 source_coverage 설정이 비어 있는 상태를 실제 확인했다. 과거 수집 완전성을 임의로 선언하지 않는다.
- 확정 재방문율과 별개로 저장된 기록 기준 재방문자·비율을 제공한다. 미방문을 확정할 수 없는 한계를 반환한다.
- 대상 프로그램뿐 아니라 추적 기간의 모든 프로그램 출석을 조회해, 출석 기록 없는 날의 재방문을 구분한다. 이 지표만으로 자발성을 단정하지 않는다.
- 추적 미완료를 수집 범위 불명과 별도 집계한다. 모든 대상이 추적 중이면 재방문 기록 수를 0으로 보고하지 않는다. 도구는 추적이 끝난 과거 대상 기간을 제안하고 후속 분석을 안내한다.
- 28일 전후 비교도 추적 완료 대상의 기록 기준 평균을 따로 제공한다. 기록 누락을 실제 0회 이용이라고 확정하지 않는다.
- 하이픈의 활성 EVERY_VISIT 입장 설문 1개에 선택형 문항 2개를 새 불변 버전으로 추가했다. 기존 질문 1개와 과거 버전·응답을 보존했다. 선택 문항이므로 입장을 막지 않는다.
- `자유롭게 쉬거나 놀려고`와 `아니요`를 모두 답한 재방문을 자기보고 기준으로 집계한다. 모름·미응답·같은 날짜의 상충 답변은 자발적으로 분류하지 않는다. 응답자 5명 미만은 해당 세부 집계를 숨긴다.
- 분석 뷰는 실제 CHECKIN 방문 영수증과 사용자에 연결된 응답의 고정 분류값만 제공한다. 자유서술이나 이름·연락처는 포함하지 않는다. anon/authenticated의 분석 뷰 직접 읽기는 차단했다.
