# 센터별 분석 필터

공통 입력은 `site`이며, 생략하면 기존과 같은 전체 집계입니다.

| 값 | 범위 |
| --- | --- |
| `ALL` | 전체 유효 공간과 프로그램 |
| `HAIFN` | 하이픈 |
| `ENOUGH_PLACE` | 이높플레이스 |

운영 요약, 프로그램 목록, 프로그램 참여, 재방문, 프로그램 전후 방문 변화에 같은 필터를 사용합니다. 결과의 `data.scope.site`에서 실제 적용 범위를 확인할 수 있습니다. 재방문과 전후 비교의 최대 요청 기간은 92일로, 7~9월 전체를 포함합니다. 기존 원천 읽기 건수·실행 시간·개인정보 보호 제한은 유지합니다.

## 기존 기록의 분류 기준

- 방문·체류: `locations`의 기존 공간 ID와 이름. 하이픈은 `2F 스퀘어`/하이픈, 이높은 `ENOUGH_PLACE`/이높플레이스입니다. 다른 공간으로 이동한 이벤트와 퇴실 이벤트도 읽어 체류시간 경계를 유지하되, 선택한 센터에서의 시간만 합산합니다.
- 프로그램·만족도: 기존 `program_location`에서 하이픈/HAIFN 또는 이높/ENOUGH가 명확한 프로그램. 비공개·리더 전용 프로그램도 기존 승인 범위대로 포함합니다. 모집 대상 지역이나 참여자의 학교로 프로그램 센터를 추측하지 않습니다. 장소가 비어 있거나 두 센터가 함께 기재된 프로그램은 센터별 집계에서 제외합니다.
- 대여: 대여 공간에 연결된 `rentals.school_id → schools.region`. 강동은 하이픈, 강서는 이높플레이스로 분류합니다. 실제 이용자의 소속 학교 기준이 아닙니다. 대여 공간 소속 지역에 따른 집계이며, 실제 장소의 별도 코드가 있는 것처럼 설명하지 않습니다.
- 설문 제출 수: 기존 `checkin_surveys.location_id`가 가리키는 공간. 질문이나 응답 수집 방식은 변경하지 않습니다.
- 스토어: 기존 주문에는 센터 귀속 연결값이 없어 센터 필터 요청에서는 `site_attribution_unavailable`을 반환합니다. 전체 집계는 유지합니다.

센터를 확인할 수 없는 공간·프로그램·대여·설문 행 수는 `scope.unclassified_source_rows`에 표시합니다. 다른 센터로 명확히 분류된 행은 이 제외 수에 포함하지 않습니다. 여러 센터를 방문한 사람은 각각 포함될 수 있으므로 센터별 순방문자 합계는 전체 순방문자보다 클 수 있습니다. 세션도 여러 공간을 거치면 센터별로 중복 포함될 수 있습니다.

재방문은 해당 센터의 방문만 추적합니다. 프로그램 참여 전후에도 해당 센터 방문만 비교합니다. 기록 완전성이 검증되지 않은 경우 확정 재방문율은 제공하지 않고 저장된 기록 기준 `recorded_*` 지표를 제공합니다. 교사 연락 여부와 자발성은 기존 기록으로 확정할 수 없습니다.

## DB 변경과 복구

`20261008010000_center_analysis_site_scope.sql`은 기존 비공개 분석 뷰 4개에 계산된 `site` 열만 추가합니다. 원본 테이블·행·설문·체크인·권한은 변경하지 않습니다. 트랜잭션 내 원천 행 수와 기존 비공개 권한을 검사합니다.

운영 반영 전 기존 정의·소유자·권한은 `scratch/center-site-view-backup.json`에 백업했습니다. `scratch/center-site-view-restore.sql`은 이전 분석 서버로 되돌린 후 적용할 복구 스크립트이며 자동 실행하지 않습니다. 운영 DB에서 전체 변경을 ROLLBACK하는 사전 검사와 로컬 PostgreSQL 호환 테스트를 통과했습니다.
